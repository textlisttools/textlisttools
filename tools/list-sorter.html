How the list sorter works

Paste your list, one entry per line, then press "A → Z" or "Z → A." The tool sorts alphabetically and treats numbers naturally, so "Item 2" sorts before "Item 10" instead of after, and it ignores capitalization so "apple" and "Apple" sit next to each other.

Nothing is added or removed — you get the same items back in alphabetical order, ready to copy.

Common uses

  • Alphabetizing a guest list, roster, or contact list
  • Sorting product names, SKUs, or file names for review
  • Putting a randomly ordered or shuffled list back into a predictable order
  • Prepping a list for a spreadsheet or document that expects A-Z order

FAQ

Does it sort numbers correctly?
Yes — it uses natural number sorting, so "Item 9" comes before "Item 10" instead of after it.
Does capitalization affect the sort order?
No — sorting ignores case, so "apple" and "Apple" are treated the same.
Is my list saved anywhere?
No. Sorting happens locally in your browser and nothing is uploaded.
