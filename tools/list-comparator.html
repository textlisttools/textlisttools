How the list comparator works

Paste one list into each box, then pick what you want to see: items only in List A, items only in List B, or items that appear in both. Comparison is exact-match and case-sensitive, with each list de-duplicated automatically before comparing.

The result keeps the original order from whichever list it came from, so nothing gets rearranged unexpectedly.

Common uses

  • Finding who's on one guest list or roster but not another
  • Comparing two exported spreadsheet columns for differences
  • Checking which entries overlap between two mailing lists
  • Spotting what changed between an old and new version of a list

FAQ

Is the comparison case-sensitive?
Yes — "Alex" and "alex" are treated as different entries. Make sure both lists use consistent casing if that matters for your comparison.
Does it remove duplicates within each list first?
Yes — each list is de-duplicated before comparing, so repeats within a single list don't affect the result.
Are my lists saved anywhere?
No. Comparison happens locally in your browser and nothing is uploaded.
