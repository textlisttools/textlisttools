How the list shuffler works

Paste your list, one entry per line, and press "Shuffle." The tool reorders every line into a new random sequence using a Fisher–Yates shuffle, which gives every possible order an equal chance of appearing.

Nothing is added or removed — the shuffled list has exactly the same items you entered, just in a new order. Copy the result with one click once you're happy with it.

Common uses

  • Setting a random speaking or presentation order
  • Assigning random team pairings or draft order
  • Randomizing a seating chart or turn order for a game
  • Mixing up a playlist or reading list order

FAQ

Will the shuffle ever return the same order I entered?
It's possible, especially with very short lists, since every order (including the original) has an equal chance.
Can I shuffle the same list again?
Yes — press "Shuffle" again for a fresh random order at any time.
Is my list stored anywhere?
No. The shuffle happens entirely in your browser and nothing is saved or sent anywhere.
