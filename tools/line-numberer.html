How the list line numberer works

Paste your list, one entry per line, pick a style, and press "Add numbering." Every line gets the same prefix — sequential numbers, dashes, or bullets — ready to paste into a document, email, or chat.

Blank lines are skipped so your numbering doesn't skip a beat.

Common uses

  • Turning a plain list into numbered steps for instructions
  • Formatting a list for a document, email, or chat message
  • Converting a list into markdown-style bullets or dashes
  • Prepping an agenda or checklist for printing

FAQ

Does it renumber if I add or remove lines?
Only when you press "Add numbering" again — it's not live, so edit your list first, then apply numbering.
Can I change the numbering style after applying it?
Yes — edit the original list in the top box (not the result), change the style, and run it again.
Is my list saved anywhere?
No. Everything runs locally in your browser and nothing is uploaded.
